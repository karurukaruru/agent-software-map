# Changelog

All notable changes to Agent Software Map will be documented here.

This project follows [Semantic Versioning](https://semver.org/). Dates use `YYYY-MM-DD`.

## [Unreleased]

## [1.1.0] - 2026-10-11

### Added

- Fourteen focused After Effects / PV workflow cards and a task index.
- Candidate recipes for typography, illustration rigs, camera motion, compositing, shapes, modular scenes, and delivery.

### Changed

- Generalized examples and clarified evidence, runtime probe, and visual verification boundaries.
- Corrected text fill handling, root-composition identification, audio-state checks, and frame-rate conversion guidance.

### Validation

- Repository validation, relative Markdown links, whitespace checks, and GitHub Actions validation passed.
- This release has not been tested inside After Effects and does not claim measured agent-performance gains.

## [1.0.0] - 2026-08-14

### Added

- The Agent Software Map design and generator Skill.
- Object relationships, stable addressing, and decision-relevant state modeling.
- Separate observation and control methods with task-specific selection rules.
- Operational contracts, real-result verification, partial-completion handling, and failure recovery.
- Retry safety, idempotency, side effects, safety boundaries, environment differences, and explicit unknowns.
- Incremental learning and update guidance based on real operation.
- Bilingual README and optional ASM templates.
- Adobe After Effects reference ASM.
- Repository validation and GitHub contribution templates.
