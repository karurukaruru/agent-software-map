# ASM：OBS Studio

> OBS Studio 是用于实时音视频采集、合成、录制和直播的免费开源软件。

## 0. 身份

| 字段 | 内容 |
|---|---|
| 名称 | OBS Studio |
| 版本 | 32.2.1 文档候选版；操作前核对实际安装版本 |
| 类别 | 录制、直播、实时音视频合成 |
| 平台 | Windows、macOS、Linux |
| 许可证 | GPL-2.0-or-later |

> **范围：** Profile、Scene Collection、场景、来源、预览、音频混音器、视频与输出设置、Studio Mode、本地录制、诊断和 WebSocket 安全。暂不覆盖插件开发和全部编码器调优。
>
> **置信度：** 基于官方文档，尚未在目标电脑实测。界面名称和可用采集方式、编码器会随平台、语言、硬件和版本变化。OBS 32.2 把“添加来源”下拉菜单改成了新对话框，因此旧版截图可能不同。

## 3. 功能卡片

### [工作区隔离 > Profile] 隔离输出设置

**介绍**

- **作用：** 将任务专用的直播、输出、音频和视频设置彼此分开。
- **入口：** `Profile` 菜单。
- **操作：** 新建或复制 Profile → 使用唯一任务前缀 → 切换后核对当前名称 → 只在其中配置输出。
- **成功检查：** 新 Profile 已激活，原 Profile 未改变。

**操作补丁**

- Profile 不保存场景和来源；这些属于 Scene Collection。
- 切换后重新核对服务、输出分辨率、录制路径和音轨。

### [工作区隔离 > Scene Collection] 隔离场景和来源

**介绍**

- **作用：** 将任务的画面布局和来源对象与已有工作分开。
- **入口：** `Scene Collection` 菜单。
- **操作：** 用唯一任务前缀新建集合 → 切换 → 添加任务场景和来源 → 切换后重新核对混音器。
- **成功检查：** 新集合已激活，原有场景未改变。

**操作补丁**

- Scene Collection 不保存输出设置，因此还需同时使用 Profile。
- 不同集合之间全局音频设备可能不同，需重新核对实际电平活动。

### [画面合成 > 场景] 创建和切换场景

**介绍**

- **作用：** 组织演示、待机等完整画面。
- **入口：** Scenes Dock 的 `+` 或右键菜单。
- **操作：** 创建命名唯一的场景 → 选中 → 添加来源 → 排序以便切换。
- **成功检查：** 选中每个场景时 Preview 显示预期布局。

**操作补丁**

- 在 Studio Mode 之外，切换场景可能立刻改变正在录制或直播的输出。

### [画面合成 > 来源] 添加和分层来源

**介绍**

- **作用：** 合成颜色、文字、图片、窗口、摄像头、媒体或其他场景。
- **入口：** Sources Dock 的 `+`。
- **操作：** 选中目标场景 → 添加来源类型 → 选择新建或已有 → 配置 → 调整层级 → 设置可见性 → 完成后锁定。
- **成功检查：** 目标来源可见、层级正确，布局完成后已锁定。

**操作补丁**

- 来源列表越靠上，画面层级越靠前。
- “添加已有”会共享同一个来源对象，修改可能影响引用它的每个场景。
- 隐藏不等于删除；部分隐藏来源仍会占用资源。

### [画面合成 > Window Capture] 只采集指定窗口

**介绍**

- **作用：** 采集指定应用，不暴露整个桌面。
- **入口：** Sources → `Window Capture`（不同平台名称可能不同）。
- **操作：** 未指定窗口时先询问 → 添加窗口采集 → 选择准确窗口 → 核对 Preview → 仅在必要时裁剪。
- **成功检查：** 只有指定窗口可见，桌面、通知和无关窗口不可见。

**操作补丁**

- 用户只要窗口时，不要改用 Display Capture。
- 最小化、受保护、GPU 加速或权限不匹配的窗口可能显示为空白；应重新核对目标和采集方式，而不是盲目点击。

### [画面合成 > 变换与锁定] 无拉伸地适配画布

**介绍**

- **作用：** 保持比例地把来源放到画布上。
- **入口：** Preview 变换框或来源右键 → Transform。
- **操作：** 选中来源 → 等比适配或缩放 → 必要时裁剪 → 检查边缘 → 锁定来源。
- **成功检查：** 无明显拉伸，重要内容可见，且不会被误拖动。

**操作补丁**

- 只有故意接受变形时才拖动侧边手柄。裁剪和缩放解决的是不同问题。

### [音频 > 混音器检查] 检查活动与重复采集

**介绍**

- **作用：** 确认哪些音频路径有真实信号，避免重复采集或反馈。
- **入口：** Audio Mixer 与 Advanced Audio Properties。
- **操作：** 播放已知声音并观察电平 → 找出活动声道 → 比较全局设备与场景音频来源 → 仅在有理由时静音。
- **成功检查：** 所需音频有信号，无多余重复声道或反馈。

**操作补丁**

- 不要凭来源名推断活动状态，要看电平。
- 未经允许，不要仅为让电平跳动而更换系统音频设备。

### [输出 > 画布与输出分辨率] 安全设置 720p30

**介绍**

- **作用：** 为测试录制配置可预测的画面尺寸和帧率。
- **入口：** Settings → Video。
- **操作：** 在隔离的测试 Profile 中检查基础画布 → 输出分辨率设为 1280×720 → 设为 30 FPS → 应用 → 重新核对 Preview。
- **成功检查：** 设置显示 1280×720、30 FPS，来源仍适配画布。

**操作补丁**

- 改变画布尺寸可能改变布局。不要改动已有用户的 Profile。

### [输出 > 录制格式与路径] 选择可恢复的本地录制

**介绍**

- **作用：** 让本地测试录制抗中断且易于查找。
- **入口：** Settings → Output → Recording。
- **操作：** 检查可用模式和编码器 → 可用时选择 MKV 等抗中断容器 → 选择可写路径 → 使用本机实际可用的编码器 → 应用。
- **成功检查：** 重新打开设置后，所选格式、路径和编码器仍然保留。

**操作补丁**

- 不要假设本机一定有 NVENC、AMF、QSV 或其他硬件编码器。
- 如果必须用 MP4，可先录到 MKV，成功停止后再 Remux。

### [输出 > 开始和停止录制] 生成并验证本地文件

**介绍**

- **作用：** 录制当前 Program 输出，并证明生成了可用文件。
- **入口：** Controls → Start Recording / Stop Recording。
- **操作：** 先确认没有输出在运行 → 开始录制 → 观察录制指示器和计时 → 执行画面动作 → 停止 → 打开录制目录 → 检查最新文件。
- **成功检查：** 录制已停止，新文件存在且大小非零；环境允许时回看短片段。

**操作补丁**

- 绝不能把 Start Streaming 当作替代。状态不明确时先停止并检查。
- 除非用户要求，否则不要删除测试文件。

### [导播 > Studio Mode 转场] 变更 Program 前先准备

**介绍**

- **作用：** 在发往已录制或直播的 Program 输出之前，先在 Preview 私下准备场景。
- **入口：** Controls → Studio Mode。
- **操作：** 开启 Studio Mode → 辨认 Preview 与 Program → 把初始场景送入 Program → 在 Preview 准备下一场景 → 选择转场与时长 → 触发转场 → 核对 Program。
- **成功检查：** 只有转场后 Program 才改变，Preview 可独立编辑。

**操作补丁**

- 不要把仅 Preview 的改动当作已发布。要检查 Program 面板。

### [安全与诊断 > 输出状态预检] 编辑前检查

**介绍**

- **作用：** 避免误改正在直播或进行中的生产环境。
- **入口：** Controls、状态栏、可见计时器和状态指示。
- **操作：** 检查直播、录制、回放缓冲和虚拟摄像头状态 → 报告任何活动输出 → 在修改直播环境前暂停等待用户指示。
- **成功检查：** 所有相关状态已知，风险操作只在隔离且非直播的环境中开始。

**操作补丁**

- 绝不在截图、日志或报告中展示串流密钥或密码。

### [安全与诊断 > 日志检查] 用证据诊断

**介绍**

- **作用：** 用版本、设备、编码器和错误证据取代猜测。
- **入口：** Help → Log Files（具体名称随版本变化）。
- **操作：** 安全时复现一次 → 打开当前日志 → 检查时间戳和明确错误 → 分享前脱敏路径、账号名、令牌和服务信息。
- **成功检查：** 报告引用相关错误和时间，且不泄露敏感数据。

**操作补丁**

- 日志可能包含机器和账号信息。只分享必要的最小摘录。

### [安全与诊断 > WebSocket 访问] 远程控制 OBS

**介绍**

- **作用：** 允许获批的控制器查询或更改 OBS 状态。
- **入口：** Tools → WebSocket Server Settings（受支持版本）。
- **操作：** 确认确需远程控制 → 只按必要程度绑定监听范围 → 开启认证 → 把密码保存在地图之外 → 用可信客户端测试。
- **成功检查：** 获批客户端能连接，未授权客户端不能。

**操作补丁**

- 不要禁用认证或公开密码。远程输出命令属于高影响操作。
