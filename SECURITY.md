# Security Policy

## Supported version

Security fixes currently target the latest version on the `main` branch.

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled, use the repository's **Security** tab. Otherwise, open a public issue that asks the maintainer for a private contact channel without including sensitive details.

Do not publish credentials, private recordings, personal paths, tokens, stream keys, WebSocket passwords, or reproducible instructions that would expose users before a fix is available.
