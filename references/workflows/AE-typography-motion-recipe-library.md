# AE 文字运动模式库（Typography Motion Recipe Library）

> 触发：需要为文字 PV / 歌词 / Kinetic Typography **自主设计字符级运动**时，从本库选配方组合成 motion plan，而不是只让整行文字做一次 Position/Scale 或调用一个插件预设。
>
> 验证状态：可复用候选配方；使用前需在目标 AE/控制通道验证。数值为示例起点，不是通用默认。

## 1. 本库是什么 / 不是什么

- **是**：把「一段文字为什么这样动」抽象成可复用的**运动配方（Motion Recipe / Primitive）**。每个配方记录视觉特征、运动阶段、Timing 关系、参数档位、AE 实现方式、适用节奏、可组合对象。
- **不是**：工程记录、插件按钮说明、预设清单。具体镜头/文案/字体/资产属于原作者表达，不复制；只借鉴「参数档位级语法」。
- **用法**：给定陌生歌词，先按 §4 决策链定节奏/空间/情绪，再从 §3 挑 1 个主运动 + 0–1 个次级运动 + 可选相机运动，组合成 motion plan 交用户审查后执行。

## 2. 配方解剖（每个配方记录哪些字段）

```text
名称 / 英文
视觉特征    —— 观众看到什么
运动阶段    —— 分成哪几步（入场→稳定→退场），每步多久
Timing 关系 —— 字符/副本之间错多少帧、顺序、是否可逆
参数档位    —— 示例起点 + 可调方向（推断）
AE 实现     —— 用什么结构（整层 Transform / 逐字 TextLayer / Text Animator / 表达式 / PNG 素材）
适用        —— 什么歌词、节奏、情绪
可组合      —— 常与哪些配方叠加
```

## 3. 配方库

### 家族 A：缩放冲击（Punch / Overshoot）——「过冲再回稳」

**核心语法**：Scale 从 >100% 冲到稳定值，制造「砸进来」的冲击；常配 Opacity 同步升起。这是一种入场原语，只换档位不换结构。

| 配方 | 示例起点 | 视觉 | 可调方向（推断） |
|---|---|---|---|
| 标题 punch | 参数由当前分辨率、拍点与阅读时长标定 | 大字「弹」到 100% 定位 | 过冲越大越暴力；125→100 较收敛，142→100 更猛 |
| 词卡 punch | 参数由当前分辨率、拍点与阅读时长标定 | 歌词字「砸到 110%」而非 100%（落点带张力） | 落点不一定是 100%，可用 110% 保留压迫感 |
| 逐字 punch | 参数由当前分辨率、拍点与阅读时长标定 | 单字依次弹出 | 见家族 B 错帧 |
| 视频 punch | 参数由当前分辨率、拍点与阅读时长标定 | 同一角色/素材每拍「砸」进 | 可给任何 AV 层，不限于文字 |

- **AE 实现**：整层 `ADBE Transform Group` 的 `ADBE Scale` 2 keys（>100→100），线性或入线性/出贝塞尔；Opacity 1–2 keys 同步。
- **关键洞见**：落点可以是 100% 之外的「休息值」（如 110%），这是「压迫感 vs 利落感」的分界，不是错误。

### 家族 B：逐字错帧（Stagger / Per-character）——「一个字一个字地出现」

**核心语法**：把一句话拆成**每个字符一个 TextLayer**，逐层错开 in 时间 / 关键帧。是「一句歌词不是一块」的最基本实现。

| 配方 | 示例起点 | 错帧量 | 入场方式 |
|---|---|---|---|
| 大字词卡 | 参数由当前分辨率、拍点与阅读时长标定 | 3 帧/字 | 每字不同方向斜向飞入 + HOLD 三闪（见家族 D/C） |
| 3D 逐字标题 | 参数由当前分辨率、拍点与阅读时长标定 | 2 帧/字 | 每字不同方向斜漂 + 描边孪生（见家族 D/H） |
| 逐 kana 弹出 | 参数由当前分辨率、拍点与阅读时长标定 | 9 帧/字 | Scale 120→100 + Opacity（家族 A） |

- **AE 实现**：每字一个 TextLayer；in 时间（或 Scale/Opacity 首 key）按 `t_i = t_0 + i * stagger` 等间隔；字体/字号/填充/锚点一致。
- **错帧量语义**：越小越「齐/紧/稳」，越大越「碎/抖/松」。3 帧@60fps 是凌厉打拍档，9 帧是舒缓弹入档。
- **顺序可逆**：标题方案 逐 kana 标题的 in 顺序是从右往左（或从强调字起），非强制左到右。顺序本身是设计旋钮。
- **强调字**：双轨方案把拍点强调字开 `threeDLayer=true` 单独处理，其余保持 2D——「局部 3D 强调」可叠在逐字层上。
- **逐字拆字用 Vector 层还是 TextLayer？** 图形词卡方案 大字卡把每个字「文字转形状」成 `ADBE Vector Layer`（每字一个 shape 层、层名=字、字形已烘焙成路径），而非 TextLayer；这样能对单字做任意 Transform 且不依赖目标机字体渲染。TextLayer 可改文本、更省层；Vector 层适合「字形已定稿、要逐字精细动/自定义质感」的大字卡。见家族 K。

### 家族 C：硬闪（Hard-flash / Opacity Stutter）——「咔咔咔」顿闪

**核心语法**：Opacity 用 HOLD（保持）插值在 0 与 100 之间硬切，制造「打拍/闪烁」而非渐变。

| 配方 | 示例起点 |
|---|---|
| 单闪 | 参数由当前分辨率、拍点与阅读时长标定 |
| 三闪 | 参数由当前分辨率、拍点与阅读时长标定 |
| 渐现 | 参数由当前分辨率、拍点与阅读时长标定 |

- **AE 实现**：Opacity 打多个 HOLD key（`KeyframeInterpolationType.HOLD`），值在 0/100 间跳；闪烁次数由 key 数决定（0 次=冷静直接显现，1 次=单闪，3 次=顿闪）。
- **规则**：该候选的位移使用 BEZIER 缓落，闪烁永远硬切（HOLD）——两者职责不同，别混用。位移负责「到哪」，闪烁负责「节拍感」。

### 家族 D：方向性进退场（Directional fly-in / fly-out）——「从哪来、到哪去」

**核心语法**：Position 在屏幕外与就位点之间移动。**入画方向与出画方向是独立旋钮**，可任意组合。

| 配方 | 示例起点 |
|---|---|
| 逐字多方向飞入聚合（Scatter→Gather） | 参数由当前分辨率、拍点与阅读时长标定 | 每字从不同屏外方向聚成一个词 |
| 斜向飞入 | 参数由当前分辨率、拍点与阅读时长标定 | 单字斜向滑入 |
| 横扫字幕 | 参数由当前分辨率、拍点与阅读时长标定 |
| 横扫 whip | 参数由当前分辨率、拍点与阅读时长标定 |
| 坠落出场 | 参数由当前分辨率、拍点与阅读时长标定 |
| 四向散飞 | 参数由当前分辨率、拍点与阅读时长标定 |

- **AE 实现**：Position 2–4 keys。2 keys=飞入或飞出；4 keys=「飞入→停留→飞出」完整生命周期（`in→hold→hold→out`）。
- **通用三阶段骨架**（标题方案 拟声 PNG 抽象）：`飞入(0.25s) → 停留拼字(可读) → 飞出(0.3s)`，入/出方向彼此独立、可四向。这是「字来了又走」的最小可复用结构。
- **方向选择**：入画选远离主体/留白的方向；出画选下一镜头的运动流向（如整体下坠、右扫）。
- **Scatter→Gather 的职责**：不是「全句一个方向斜入」，而是「每字从各自的不同斜向飞入聚合」——这才是「随机方向错帧弹入」的观感来源。与家族 K 的「全同向横扫」「交替」「对向」互为方向编排旋钮的四个取值。

### 家族 E：重复与连闪（Repetition / Strobe）——「同一个词出现很多次」

**核心语法**：同一段文字用多个副本，在极短时间内连续出现，用「次数」制造强调。

| 配方 | 示例起点 | 副本间隔/时长 |
|---|---|---|
| 重复词连闪 | 参数由当前分辨率、拍点与阅读时长标定 | 8 副本 × 0.1s 无缝接续 |
| 递进放大重复 | 参数由当前分辨率、拍点与阅读时长标定 | 3 副本 × 0.25s，字号递增 |
| 每拍爆发字 | 参数由当前分辨率、拍点与阅读时长标定 | 每拍 1 字，配合 X 横扫 |

- **AE 实现（连闪）**：同词复制 N 层，`inPoint` 依次 +0.1s（或 +0.2s），每层 out = in + 0.1s；可给每层挂故障/glitch 效果（标题方案 用 `Mettle SkyBox Digital Glitch`）或 tracking 动画器强化「机关系」。
- **AE 实现（递进放大）**：同词复制 N 层，**用不同 fontSize 而非 Scale 关键帧**做「越来越近」——离散字号步进（544→714→792）比 Scale 关键帧更省事、观感更硬。
- **语义**：连闪=「机关枪式」重复喊叫；递进放大=「步步逼近」；每拍爆发=「重拍砸字」。选哪种看歌词是「重复喊」还是「逐步逼近」还是「重拍单字」。

### 家族 F：斜体摇摆（Skew Wobble）——「字形抖动/倾斜」

**核心语法**：用内置 Text Animator 的 `ADBE Text Skew`（倾斜）打多个 key，让整词字形左右倾斜摆动，制造「颤抖/摇摆」。

- **AE 实现**：Text Layer 加一个 `ADBE Text Animator`，其 `ADBE Text Animator Properties > ADBE Text Skew` 打多 key；Range Selector 用 start=0 全词同时。要逐字错开则给 Selector 的 Offset 打 key 或改用逐字 TextLayer + 每层 Rotate。
- **适用**：副歌标题、拟声、需要「活/抖」而非「稳」的强调字；-24 是强左倾、+14 是右倾，摆幅决定抖动烈度。

### 家族 G：弹性衰减（Elastic Decay）——「硬弹之后余震」

**核心语法**：关键帧本身做 2–4 帧硬弹，再叠 `velocityAtTime` 惯性弹跳表达式，让落点之后有余震。

- **AE 实现**：`ADBE Rotate Z`/Position 挂弹性表达式，amp/freq/decay 三参数（可写死或伪效果滑块）。
- **与家族 A 关系**：家族 A 是「无余震的 punch」，家族 G 是「有余震的 punch」；节奏越重、越要「弹」，选 G。

### 家族 H：描边孪生（Outline Twin）——「实心 + 空心 = 描边大字」

- **两种实现（候选）**：① 词卡描边版 = 整句再建一个孪生合成，各字层 `applyFill=false`（空心描边版），与实心版叠放；② 3D 标题 = 每个主字层下挂一个 `parent=主字` 的复制 TextLayer，复制层 Position 打一个静态小偏移（如 `[7,-43]`）作轮廓，随父联动。二者都是「空心孪生」，前者按合成叠、后者按 parent 挂。
- **AE 实现**：`td.applyFill = false`（或 applyStroke=true + strokeWidth）做空心版；逐字动画只打在实心层，孪生层自动跟随。

### 家族 I：自定义字形散聚（Custom-glyph Scatter）——「字不是字体，是素材」

- **AE 实现**：逐张 PNG 打 Position 4 keys（飞入→hold→hold→飞出）+ Opacity 淡入，各自独立方向/错帧（家族 D 的三阶段骨架）。
- **为什么这么做**：字体给不了的手绘/特制字形、每字独立质感和运动。代价是无法一键改文本——适合**拟声、标题字、装饰字**这类「少量、高设计感」的字，不适合整段歌词。
- **边界**：`[推断]` 具体 PNG 的绘制/来源授权不明，Agent 自建时应自绘或取得授权字形，不复制原素材。

### 家族 J：相机 + 文字（Camera + Typography）——「字是空间里的物体」

- **语义**：文字「在空间中穿梭/被镜头扫过」的深度感，与逐字运动正交——可以「逐字弹出（家族 B）+ 相机推进（家族 J）」叠加。

### 家族 K：逐字方向编排与对撞（图形词卡方案 大字卡）`[待验证]`

**核心语法**：一句话的每个字是独立层（图形词卡方案 用 Vector 层，逐字词卡方案/标题方案 用 TextLayer），入场时**每个字的运动方向、字号、旋转各自独立编排**，形成整句的「运动编排」。以下五种子模式可按设计组合，互相可组合。

| 子模式 | 示例起点 | 视觉 |
|---|---|---|
| 交替方向 | 长句大字卡：相邻字 Y 上下交替入场（如 722→345、117→479、747→468、117→519） | 相邻字上下交替入场，制造「波浪/抖动」 |
| 同向横扫 + 回声 | 参数由当前分辨率、拍点与阅读时长标定 | 整句像「回声」一样多波扫过 |
| 对向横扫 | 两个词对置：左词 `[1059→545]` 左扫、右词 `[275→736]` 右扫，向中心对撞 | 两词从两侧向中间聚 |
| 递降字号横扫 | 4 字句：445px→195px→153px→153px，同向左扫 | 「由大到小」透视/级联扫入 |
| 双副本对撞 + 旋转归零 | 单字双副本：`[1162→1267]` 右滑 rot 30→0，`[1408→1267]` 左滑 rot -30→0 | 一个字的两份副本从两侧对撞合并，旋转归零 |

- **AE 实现**：每字独立层（Vector 或 TextLayer），Position 2 keys（屏外→就位）+ 可选 Rotation 2 keys（±N°→0）+ Opacity（可加顿闪，见家族 C）；错帧按家族 B。
- **方向编排是旋钮，不是固定**：同一句里每字的入画方向可「全同向」（横扫）、「交替」（波浪）、「对向」（对撞）、「双向副本」（合并）——按歌词情绪选。横扫=铺陈/过场，交替=俏皮/抖动，对撞=强调/集结，双向合并=强调单字。
- **回声 = 副本错时**：把同一句复制 2–3 份，`inPoint` 依次错开，就是「回声/残像」；不必逐字重做。
- **递降字号**：首字用超大字号（445px 量级），后续递减，制造「从大屏推向小字」的透视级联，配合同向横扫最自然。

### 家族 L：烘焙空心字形 + null 父级整句卡（Baked-outline Glyphs + Parented Phrase Card）`[待验证]`

**核心语法**：在图像/舞蹈主导的 PV 里做一句歌词卡时，把整句 TextLayer **禁用当源**，逐字转成「空心字形」ShapeLayer（字形烘焙成路径，**不依赖目标机字体渲染**），全部字符 **parent 到 1 个 control null**；整句组运动写在 null 上，逐字节奏用 inPoint 帧级错开。两级运动解耦：null 管「整句去哪」，inPoint 管「每个字什么时候露」。

- **AE 实现**：文字层的 Create Shapes from Text 操作（需目标环境探测）把每字烘焙成 Shape 路径 → 命名 `X Outline` → 逐字在 `/同步选中的图层/父级到 NULL` → 空 null 打整句 Position 2 keys（屏外→就位，LINEAR 横扫或 BEZIER 缓落）；字符在时间线上按 inPoint 阶梯错 1 帧。
- **设计效果**：空心字形本身是「文艺/利落/去字体依赖」的观感；null 让整句先当「一个整体」建立，逐字 1 帧阶梯再给「活/层层点亮」的次级节奏。适合**大信息量画面的薄歌词标注**，不与主画面抢镜。
- **何时选它（对比家族 B/K）**：家族 B/K 拆 TextLayer/Vector 逐字动是「字是主角、逐字形态是主体」；家族 L 的克制折中——**字形烘焙 + null 组运动**让一层结构同时表达「整句」与「逐字」，录制/复用成本低、观感统一，适合**以图为重、歌词为注**的镜头。
- **变体**：null 横扫（此例）/ null 上推 下坠；字符 inPoint 左→右 / 从强调字起；空心描边加粗改实心填充；逐字再各挂独立 Position offset 叠「浮起」。

### 家族 M：逐字竖直 Drop-in + 乐句错帧（Per-char Vertical Drop, Phrase-pitched Stagger）`[待验证]`

**核心语法**：一句歌词**每个字符一个 TextLayer**，X 固定在自己的列，只动 Y：字符从就位点上方/下方**竖直 drop-in**（带一次过冲再回稳），相邻字**错帧 ≈1 帧**，但错帧**按乐句分组**（词内 1–2 帧、词间停顿）而非全程匀速。全片黑底 + 近白（243,243,243）填充/描边，同一短语内**混掺纯填充字与纯描边字**。

- **AE 实现**：每字一个 TextLayer（68px、近白、锚点不动、X 固定），Position 打 4–6 个 **不规则手工关键帧**（非均匀 EaseEase）：drop → 过冲 → 回稳，末段 2 key 体现「越过+回弹」；inPoint 阶梯错帧、**按乐句分组**。
- **Timing 洞见**：这是「**弹簧式竖直落位**」而非 screen-off 飞入——字符从就位点相邻的 Y 值高低冲进来，过冲量很小（~2px）但节奏感强；X 永远不动=字符只在自己的「坑位」竖直弹入。错帧**不匀速**、按乐句 1 帧/词内+词间休息，是「成熟 vs 机械」的关键差异。
- **配色**：纯黑底 + 243,243,243 近白填充/描边混用 = 单色克制，靠「填充 vs 空心」制造层次而非彩色。

### 家族 N：巨型词卡对位落点 Drop+Overshoot（Giant Word Card, Opposing-landing Punch）`[待验证]`

**核心语法**：超大字号（300px 级）关键词作为**一块词卡**，从就位点竖直 drop-in 带明显过冲回稳；两个反义词卡**落点刻意对位**（一个偏低、一个归中/另一侧），配合错峰入场制造「最低/最高」式字面-视觉双关。

- **AE 实现**：词卡整层 Transform 打 8–10 个不规则 key：快速 drop → 多次小幅过冲 → settle；多用 3–5 个中间过冲值（`524→531→546→540→549→540`）制造「砸下来还在晃」。
- **设计效果**：大字号关键词**本身承担主视觉**；反义词对位落点 + 错峰 = 用空间与时间表达语义（低/高、近/远），不依赖颜色。
- **与家族 A 关系**：家族 A 是 Scale punch；家族 N 是 **Position 竖直 drop + 多过冲** 的「位移版 punch」，落点带明显多段晃动而非一处。

### 家族 O：中央描边水印 + 填充字抖动出画（Centered-outline Watermark + Fill-word Jolt-then-sweep-out）`[待验证]`

**核心语法**：同一「大词」（290px 级）提供**两个版本**——静态描边(空心)版固定在**屏幕中心 [960,540]** 当水印/底衬，动态填充(实心)版在其**自己的某一行 Y** 上做「**入 → 向左抖摆落位(过冲回稳) → 停顿 → 向右横扫出画**」。同一词填充层横移、描边层居中不动，形成「词扫过 + 中心留影」的双层关系。

- **AE 实现**：一行一个填充 TextLayer，Position 打 8–12 key（入→左摆→停顿→右扫出画）；同词再建一个 applyFill=false 的空心、strokeWidth 的静态层置画面中心。多词并排时各置一行、同刻入场。
- **设计效果**：「词横向行程 + 中央留影」比单向 L→R 扫更有"行进/位移"叙事；填充词先向目标位抖摆再统一向右离场，节奏是「落定 → 出发」两拍。与家族 K「同向横扫」区别是**中央显式描边水印孪生 + 落位抖摆 + 出画右侧**。

### 家族 P：逐字旋转弹簧散落（Per-char Rotation-spring Scatter）`[待验证]`

**核心语法**：单字从就位点上方**旋转着跌落/散入**，Rotation 用**显式手工关键帧**模拟弹簧衰减（`+90→-33→+24→-10→+3.5→0`），同时 Position 竖直下落；若干小字（68px）错帧散落在副歌/句尾，制造「字从空中旋落拼成词」。

- **AE 实现**：Rotation 打 5–7 个交替正负、幅值每步约减 60%（90→33→24→10→3.5）的阻尼序列归 0；Position 2–3 key 竖直下落；逐字 inPoint 错 1–2 帧。
- **设计效果**：与家族 B/K 的「平移错帧」比，这是**明显带旋转自转的散落**，更「活/俏皮」；适合短小歌词、拟声、关键词的单字强调。
- **关键洞见**：`[手动弹簧关键帧 = 负号递减振荡]`——不必上 elastic 表达式，手摆几组 `+A/-（~0.6A）/+（~0.4A）/-（~0.1A）` 精度已足够「弹」。与家族 G（velocityAtTime 表达式）互为轨道以外的弹簧实现。

### 家族 Q：逐字共享起点扇出组字 + 重音弹脉冲（Per-char Shared-origin Fan-out Assembly + Beat Pulse）`[待验证]`。

**核心语法**：一句歌词**逐字烘焙成独立矢量字形（AI/PSD AV 层）**（AE 无 TextLayer），每字 parent 到各自的 **control Null**；所有字从**同一个共享起点**以 **Scale 0→100 pop + Rotation -40°→0 whip** 的方式**扇出到各自的最终列**，在屏幕上横向「一个个排成一行」；落位后承载乐句重音的个别字再叠 **Scale 脉冲 100→120→92→100（×2）** 做与节拍的强调。

- **AE 实现**：每字一个烘焙 AV 字形层 + 一个空 Null，把字形 `父级` 到 Null；字的手部运动全写在 Null（Position 2 key 共享起点→列、Scale 2 key 0→100、Rotation 2 key -40→0）；逐字 inPoint/首 key 错 1 帧。重音字用同一/相邻字层再打 4 key Scale 脉冲。组字完成后若有出画，各字 Null 末 2 key 向各自方向飞出。
- **与家族 M/K/D 区分**：家族 M 是「各字固定列、X 不动只竖直 drop」；家族 D/K 的 Scatter→Gather 是「每字从各自不同方向飞入聚合」；**家族 Q 是所有字从同一单点扇出 + 带旋 whip + 落位后弹脉冲**——它是「配乐填词」动画里最常见的逐字打法之一，节奏感来自错帧与重音脉冲两处。
- **变体**：共享原点可放屏外（大字从中心/屏幕角落扇出整行）；Rotation whip 幅度 ±45°；重音脉冲只打核心词或每拍打。

### 家族 R：号令爆发字的字形碎片爆散聚位（Per-stroke Fragment Explode-Assemble under Punching Null）`[待验证]`。

**核心语法**：高能量号令/拟声/惊奇字（口令、命令、爆发词）不用整字，而是**把每个音节拆成几十片图形碎片 AV 层**（独立的图形碎片，非 AE text），每片**独立手打 20–26 个 Position 关键帧**：从散落起点飞向自己槽位→落位后残留微颤；全部碎片 **parent 到 1–4 个 control Null**，Null 打 **Scale punch `0→38→100→129→100`（≈4 帧过冲）**。整字"砸下 + 抖落成字"。

- **AE 实现**：把烘焙字形按笔画/色块切碎成许多独立 AV 层（用允许修改的自建字形生成），每片一个 TextLayer 转形状/预制碎片；每片 Position 打 20+ 手打 key：散落起点（通常分散在上/周围）→ 目标槽位（纵向坠落/横向归位）→ 落位后 3–6 key 小幅往复=微颤；全部碎片父级到 1 个 punch null，null 打 `0→~130→100` 四帧 Scale 过冲。
- **设计效果**：单一片结构给人「字是在原地稳坐」；碎片结构给人「号令一出、整字轰然砸下并抖抖地拼好」。**能量/主观越强的字越用碎片**，平静说明偏爱整字卡。
- **与家族 A/Q/I 区分**：家族 A 是整层 Scale punch 且无碎片；家族 Q 是整字形经单个 null 扇出组字（字不破碎）；家族 I 是每字一个单素材整体动；**家族 R 是字被切开成多片、每片独立动、再在 punch null 下当一把砸下**——三者能级递增。
- **变体**：碎片量（单片字→上百片）；碎片漂移幅度（聚拢 vs 爆散）；null punch 过冲（129 偏脆、150+ 更爆）；落位微颤圈数（0=干脆落稳，2–3 圈=抖落感）。

## 4. 决策链：陌生歌词 → motion plan

给定一句没见过的歌词，不要默认「整层 Position/Scale」。按此链条推导：

```text
0. 先定「原子载体」-> 逐字/词要在 AE TextLayer 里动(可改文案)-> M/N/O/P；文字是定稿的手绘/拟声/大标题/烘焙矢量 -> 用 imported AI/PSD 或烘焙字形 + control Null(家族 L/Q)，威力不够再拆碎片(家族 R)
1. 定信息层级  -> 主歌词=逐字 lyric 卡(家族 M 竖直drop 乐句错帧)；句中情绪词=巨型词卡(家族 N 对位落点)；铺陈多行=水印+扫出(家族 O)；短语指令/拟声=烘焙号令字(家族 Q/R)；拟声单字=家族 I/P
2. 定节奏      -> 打拍/凌厉 -> 短错帧(3帧) + 多闪(3闪) + 硬弹(G)；舒缓/叙事 -> 长错帧(9帧) + BEZIER 缓落；**逐字主歌 -> 词内 1 帧、词间停 0.2–0.9s 的乐句分组错帧(家族 M)**，不要全程匀速
3. 定空间      -> 入画方向远离主体/往留白；出画方向顺下一镜头流向；要深度感才加相机(J)；字符 X 恒定/扇出/竖直 drop 是 M/Q/M 的空间旋钮
4. 定情绪      -> 重拍/爆发 -> 家族 G 弹性 或 家族 E 每拍爆发 或 家族 R 碎片爆散；口令/命令/惊奇 -> 家族 R；颤抖/拟声 -> 家族 F 斜体摇摆 或 家族 P 旋转弹簧；压迫 -> punch 落点 110% 而非 100%
5. 组合        -> 主运动(入场) + 次级运动(质感，如 F/I/P) + 可选相机(J)；每个效果只承担一个语义职责(entry/readability/emphasis/transition/depth/texture/unification)；落位后可叠「重音字 Scale 脉冲 100→120→100」(家族 Q/M) 或「过冲多段」(M/N)
6. 生成 motion plan（结构+参数档位+理由）交用户审查，再执行
```

**组合原则**：一次入场通常 = 1 个「到哪」(D 方向 / M 竖直 / Q 扇出) + 1 个「怎么出现」(A punch / B stagger / C flash / E repetition / M 乐句错帧) + 可选「质感」(F skew / G elastic / H twin / P 旋转弹簧)。烘焙字形用 null 父级(L/Q)，逐字骨架+振荡写 null、碎片化只在高能号令字用(R)。不要给同一文字同时堆多个同职责运动。

## 5. 参数档位速查表

| 旋钮 | 示例起点 | 语义 |
|---|---|---|
| 错帧量 | 2帧@30 / 3帧@60 / 9帧@60 | 越小越齐越凌厉，越大越碎越松弛 |
| 闪烁次数 | 0 / 1 / 3 次 | 0=冷静直接；1=单闪；3=顿闪打拍 |
| punch 过冲 | 120 / 125 / 142 → 100（或落 110） | 越大越暴力；落点 >100 可保留放大状态 |
| 字号档位 | 250px 大字卡 / 131px 3D 标题 / 64px 字幕 / 320px 连闪 / 445px 逐 kana / 758px 爆发 | 由信息层级决定，见 §4 第 1 步 |
| 位移插值 | BEZIER ~0.6s 缓落 | 该候选使用缓落；匀速或硬切按 brief 选择 |
| 闪烁插值 | HOLD | 闪烁永远硬切，不缓变 |
| 弹跳 | amp/freq/decay（velocityAtTime） | key 越猛余震越狠 |
| 乐句错帧间距 | 词内 0.042（1帧@24）/ 词间 0.2–0.9s | 逐字主歌：词内紧、词间停（家族 M），非匀速 |
| Fill/Stroke 交替 | 相邻字一实一空、全段 50/50 | 用"明/空"对比做层级，不靠彩色（家族 M） |
| 落位过冲量 | 竖 drop 微过冲 2px / 词卡 549 vs 540 | 微翻=利落；多段=仍晃动（家族 M/N） |
| 手动弹簧旋转 | 90→-33→24→-10→3.5→0（阻尼递减） | 显式关键帧弹簧，独立于 velocityAtTime（家族 P） |
| punch 过冲（卡片） | 0→115→100 / 0→129→100 | 数字越大越"砸"/越爆（家族 N/R） |

## 6. 诚实边界

- 这些示例取值与变体都是 `[推断]`，可执行但未逐镜头验证；Agent 执行后回读 keys/插值并抽帧，必要时请用户确认，不冒充候选。
- 机器只断言结构/时序/边界/文本正确；「有情绪 / 日系感 / 弹得自然 / 抖得好看」必须人工审查。
- 不得牺牲歌词可读时长（出场不早于 `readable_until`）；装饰性运动（F/G/I）不得吞掉整句。
- 所有具体文案、字体、PNG 字形、镜头设计属原作者表达，只借鉴参数档位级语法，不复制资产。

## 7. 跨域统一运动语法（文字 ⇄ 插画）`[待验证]`

**核心洞见：被动画的「原子」随域而变（字符 / 插画零件 / PNG 字形 / 视频素材），但「动词」（运动原语）是同一套。** 学会文字运动 = 学会插画运动 = 学会任何「把离散单元逐个动起来」的运动设计。[插画动起来](AE-illustration-motion-rig.md) 提供迁移候选——它的每个原语都能在本卡找到同源家族：

| 运动原语（动词） | 文字域实现（本卡家族） | 插画域实现（插画模板） | 共同本质 |
|---|---|---|---|
| 硬闪 / 状态硬切 | 家族 C：逐字 Opacity HOLD 三闪 `50→0→100→…` | 差分轮播 A→B→C→B→D @0.29s/态（纯切层） | 状态在离散值间硬跳、不插值 = 节拍/活物感 |
| 重复 / 连闪 | 参数由当前分辨率、拍点与阅读时长标定 | 同一位置按当前拍点轮播差分 | 同原子按时间偏移重复 N 次 |
| 错帧 / 级联 | 参数由当前分辨率、拍点与阅读时长标定 | 多个 comp 实例 in/out 错开 | 同一偏移量作用于每个单元 |
| 弹性衰减 | 家族 G：velocityAtTime + amp/freq/decay | 自建阻尼控制参数（效果滑块读参） | 硬弹后按末速惯性余震 |
| null 父级 rig | 家族 J/H：相机/描边孪生 parent 到 null | 角色部件 parent 到对应控制 Null | 动画写在父级，子层跟随 |
| 方向编排 | 家族 D/K：同向/交替/对向/Scatter→Gather | 多面板 fan-out（8 null 外扩） | 单元入/出方向的编排 |

**插画域独占原语（可反向迁移到文字）**：
- **loopOut 待机循环**：`3 键 A→B→A + loopOut()` 做无限呼吸/悬浮——文字标题同样可用（此前文字库只有一次性进退场，无「无限待机」档）。
- **表达式开关切换**：`if(控制层.effect("X")(1)==1){100}else 0` 非破坏切换（表情/口型/字幕语言版）——等价于把「差分轮播」从时间线切层升级成表达式开关。
- **镜像复用**：`Scale X=-100` 画一边翻出另一边（左右对称零件）。
- **零件分解**：拆件粒度 = 「哪些部位独立动 + 独立切换」，不动的并成大件。

**结论**：本卡 §3 家族 A–R 与 §4 决策链，把「原子」从字符替换成插画零件后可作为候选——错帧量/闪烁次数/punch 过冲/位移插值/HOLD 等旋钮需按部件尺度与运动目的重新标定。跨域迁移时只需换「原子」与「拆件」，不用换「动词」。
