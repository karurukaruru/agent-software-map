# AE 插画动起来（Illustration Motion Rig）——「把一张图拆成零件再动」

> 触发：需要给一张**静态插画/立绘**做「让它活起来」的动画（呼吸、眨眼、口型、待机摆动、表情切换、多面板编排）时，用本卡；区别于 [文字运动模式库](AE-typography-motion-recipe-library.md)（原子是「字符」，本卡原子是「插画零件」）。
>
> 验证状态：可复用候选配方；使用前需在目标 AE/控制通道验证。数值为示例起点，不是通用默认。

> 统一视角：本卡所有原语与文字运动原语同源，见 [文字运动模式库](AE-typography-motion-recipe-library.md) §7「跨域统一运动语法」。

## 1. 这套模板在做什么

可以把一张自建插画拆成零件 + 若干张差分，复用运动结构。两个正交层：

- **零件层（Level 2）**：单张插画内部，把脸/头/身体/手/腿拆成独立 shape 层，用 null 挂起来动（rig）。
- **编排层（Level 1）**：主时间线上，把「一段插画运动」这个合成当原子，做网格平铺、频闪切换、级联错帧。

## 2. 核心机制 A：差分轮播（State-swap Animation）——「用 2–4 张画假动作」

**不逐帧画动画，而是把同一插画画成 N 个略有差异的状态，快速硬切轮播。**

| 实例 | 示例起点 |
|---|---|
| 两态切换 | 中性→强调→中性；每态持续帧数按当前节拍设置 |
| 多态轮播 | 多个强调态之间插入中性回位态 |

- **节律语义**：`A→B→C→B→D→B→C→B` 里 **B 出现 4 次**，夹在每个独特态（A/C/D）之间——B 是「中性/回位」态，A/C/D 是「强调/摆动」态。**中性态当回位帧**是差分轮播的核心节律，等价于文字硬闪里的「0/100 之间的 HOLD 往返」。
- **AE 实现**：每个状态一个 comp 实例，`inPoint` 依次 +0.29s、`outPoint = in + 0.29s`；无 Transform 动画，纯「切层」。等价于文字域的家族 E（重复连闪）+ 家族 C（硬闪），只是原子从「字符」换成「差分插画」。
- **为什么快**：少量差分能形成离散切帧的观感（`Posterize Time` 同源思想），可减少逐帧绘制量，实际节省程度取决于素材。

## 3. 核心机制 B：null rig + loopOut 待机循环（Idle / 呼吸）

**把零件挂到 null 上，null 打 3 键 A→B→A + `loopOut()` 无限循环，做出呼吸/摆动。**

- **结构**：3 键「起→去→回」（值 A→B→A，回到起点）构成回到起点的 cycle；`loopOut("cycle")` 重复整段，`loopOut("pingpong")` 才是正反往返播放。振幅（3px vs 13px）决定「微呼吸」还是「明显摆动」。
- **AE 实现**：`ADBE Position` 打 3 keys（A→B→A），expression = `loopOut()`；零件（Head / Arm_R / Arm_L）`parent` 到 null，动画全写在 null 上。
- **迁移到文字域**：文字标题同样可用「3 键 + loopOut()」做无限待机悬浮/呼吸，这是本卡对文字模式库的**新增可迁移原语**。

## 4. 核心机制 C：表情制御（Expression Switch）——「复选框切换表情」

**用控制层的 Checkbox Control + 各表情层的 opacity 表达式，非破坏地切换表情。**

- **结构**：一个「主控层」持有 N 个开关（checkbox 1/0），N 个「可变层」各读一个开关决定显隐。**这是「差分轮播」的表达式版**——不需要在时间线上切层，改 checkbox 即切表情，且不破坏其他层。
- **AE 实现**：`Checkbox Control` 效果（值 0/1）→ 目标层 Opacity 挂 `if(...)(1)==1 {100}else 0`。该结构允许多个开关同时开启；需要「多选一显隐」时改为一个状态索引/下拉控件，或先检查开关互斥。可用于（表情/口型/道具/字幕语言版）。
- **关键坑**：`effect("表情A")(1)` 是 Checkbox 的 **value 索引**（第 1 个子属性），不是 `effect("表情A").value`——复选框控件的取值要走 `(1)`。

## 5. 核心机制 D：镜像复用（Mirror Part Reuse）——「画一边，翻出另一边」

- **AE 实现**：同一零件复制一层，Scale X 取负。省一半绘制量，且左右天然对称。
- **边界**：镜像只对「对称零件」成立（手臂/腿/翅膀/发片）；有文字/徽章/不对称纹理的零件不能镜像（会反字/反图）。文字域偶尔也用，本原语主要是插画/角色域。

## 6. 编排层（Level 1）：把「一段插画运动」当原子编排


| 编排 | 示例起点 | 语义 |
|---|---|---|
| 网格外扩 | 多个组件的控制 Null 向两侧移动 | 展开主体群 |
| 同位切换 | 组件在同一中心按拍点切换 | 重拍强调 |
| 级联 | 组件的 in/out 依次错开 | 分步推进 |

- **AE 实现**：合成实例 + null 父级定位（grid = 静态 null 位置；fan = null 打 2 keys；级联 = in/out 错开）。**null 是「定位手柄」，comp 实例是「原子」，两者正交**——和文字域「逐字层 + parent 孪生」同一思路。

## 7. 零件分解清单（部件拆分）——「拆哪些件」

- **通用拆法**：`Guide`（参考线，不参与渲染或仅作对位）→ 分层级零件（头/脸/身体/手臂×2/腿×2/手持道具）→ 需要动的部位挂 null → 需要切换的部位建表情差分层。拆件粒度 = 「哪些部位要独立动 + 哪些要独立切换」，不动的并成大件即可。

## 8. 决策链：静态插画 → 运动方案

```text
1. 定目标      -> 只要「活」（呼吸/眨眼/口型）→ 差分轮播 + null loopOut；要「切换」（表情/口型）→ 表情制御表达式开关
2. 定拆件      -> 哪动拆哪：头动拆 Head 挂 Head_Null；手臂动拆 Arm 挂 Arm_Null；左右对称用镜像复用省一半
3. 定差分      -> 手绘 2–4 态（A/B/C/D），中性态当回位帧；0.29s/态（7帧@24）起步
4. 定编排      -> 单个角色多面板 → grid/fan；打拍强调 → 中心频闪；流水过场 → 级联
5. 组合        -> 零件 rig（Level 2）+ 编排（Level 1）可叠加：网格里的每个面板内部还在差分轮播
```

## 9. 诚实边界

- 参数迁移先声明保留秒数还是保留帧数；24fps 的 7 帧约 0.292s，保留时长到 60fps 应取约 18 帧，保留 7 帧则缩短到约 0.117s。
- 本卡的核心是差分 + Null + 自建表达式；如增加第三方效果，先探测依赖，缺失时视觉结果保持 unverified。
