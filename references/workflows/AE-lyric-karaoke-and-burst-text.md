# After Effects 逐字歌词 Karaoke + 拟声爆发字（双轨分层）

> 触发：逐字歌词随歌出入、重拍强调字与舞者/角色合成。
> 验证状态：可复用候选配方；使用前需在目标 AE/控制通道验证。数值为示例起点，不是通用默认。

## 1. 工程骨架

- 主合成：定稿音频 + 角色场景预合成 + 歌词预合成 + 额外装饰。
- 歌词与场景分开维护；disabled 备用层列入清单，不自动删除，也不推断禁用原因。
- 工作与交付 fps 按实际需求确定；备用音频的 audioEnabled 单独检查，避免重叠播放。

## 2. 两套文字系统

### 2.1 逐字歌词

- 需要字符独立运动时使用逐字 TextLayer 或内置 Text Animator/Selector。
- 用文本 manifest 记录字符/词组、字体、in、可读停留、out 与 operation_id。
- 候选入场是 Opacity 显现 + Scale 过冲回稳；例如 120%→100%，时长按拍点和字号重新标定。
- 硬切用 HOLD，快速渐变与硬切分别记录；不能把 LINEAR 两帧渐变称为严格硬切。

### 2.2 爆发强调字

- 与歌词层分开定义字号、颜色、位置与可读时段；不继承某首歌曲的具体拟声词。
- 候选横扫用四阶段 Position：屏外→落位→持有→屏外；可叠少量 3D 倾斜。
- 按当前重拍安排副本，每个实例有独立 tag；数量和速度来自当前音乐。

## 3. 差分/图片切换

- 自建图片序列可按节拍切换；层 in/out 根据 manifest 生成。
- 先确认需要无缝切换还是有意重叠；后一层覆盖前一层的关系要回读。
- 不复制来源视频的图片编号、精确时段或角色姿势。

## 4. 合成与验收

- 读 TextDocument、字体实际解析、timing、keys/interpolation、3D、source 与启用状态。
- 合成背景色只是查看背景的一项设置，不能证明素材已键控；读取素材/effect/alpha 并观察实际边缘。
- 使用目标 AE 中实际可用的 Keylight 等键控能力，缺失时记录限制，不把未经处理素材称为键控成功。
- 入场/稳定/退场和关键拍点分别采样，检查阅读、遮挡、黑帧与音画同步。
- 缺字体、媒体、效果或渲染通道时，结构检查可以完成，但视觉结果保持 `unverified`。

## 5. 恢复与相关卡

- timeout 后先查 tag、层数量、source、in/out 与 key times；只补缺失操作，不整段重放。
- 使用 [歌词文字动画](AE-lyric-text-animation.md)、[文字运动模式库](AE-typography-motion-recipe-library.md) 与 [合成与素材融合](AE-compositing-and-material-integration.md) 选择实现。
