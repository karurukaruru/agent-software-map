# AE MAD/PV 生产语法（可复用配方）

> 触发：从零搭建或分析一支 MAD / 音乐 PV 工程：项目架构、节拍对齐、歌词字幕、抽帧节奏、大字动画、混合帧率交付。
>
> 验证状态：可复用候选配方；使用前需在目标 AE/控制通道验证。数值为示例起点，不是通用默认。

## 1. 工程架构模板 `[待验证]`

```text
!!Final_Render   # 交付合成（如需 60fps 容器，见 §8）
!!Main           # 总时间线（工作帧率，如 30fps），全片长度 == 音频长度
 !Part_n         # 段落级长合成（几十层，覆盖 10-30s 段落，含背景/长卷）
 !MAD_n          # 镜头级短合成（2-5s，各只被引用一次）
 Lyrics          # 歌词字幕条带合成（见 §4）
 UniversalAudio  # 共享音频合成（见 §3）
 内容合成        # 自然语言命名（中文即可），按内容自由组织
```

- 命名规则：`!!` 前缀 = 主合成（仅是命名约定；排序取决于当前面板设置）；`!MAD_n` = 镜头序号；`!Part_n` = 段落。合成名可含中文。
- **主合成识别法**：构建"合成被合成引用"的引用图，未被其他合成引用的根合成只是主合成候选；可能有多个未使用根节点，仍需核对 Render Queue、音频、时长和 brief。比按名称猜可靠，Agent 分析陌生工程时必用。
- 共享组件可能被多次引用。高引用数的小合成可能是共享组件；必须读取 source 与音频状态后判断（§3），不要当内容层删改。

## 2. 节拍网格层（bpm 层）`[待验证]`

**是什么**：`!!Main` 顶层一个禁用的引导层（名如 `▚ 180bpm`），Position 上打满等间隔关键帧 = 时间线上的可视节拍尺。需要对拍的镜头可量化到该网格；歌词、呼吸和自由节奏段按实际人声时序。

**数学**：30fps 工程、BPM=B 时每拍间隔 `60/B` 秒（180bpm → 0.3333s = 每 10 帧一拍）。需要对拍的切点可取间隔的整数倍，随后再量化到实际帧边界。

**Agent 生成配方**（自建工程时）：
1. 建一个 solid/null 引导层放最顶层，禁用视频显示，并单独记录 audioEnabled；
2. 用脚本循环对 Position 打 keys，`t_i = i * (60/BPM)`，值任意（如 [0,0]）；
3. 需要对拍的 in/out/keyframe 时间先量化到 `round(t / beat) * beat` 再写入。
4. 校验：回读 keyTime 序列，在未量化秒轴上 diff 为 `60/BPM`；对帧量化时允许一帧内误差，不累积按整帧步进的漂移。

## 3. UniversalAudio 共享音频合成 `[待验证]`

**模式**：一个极小合成（如 50x50）内只放最终音频单层；作为**禁用图层**放到每个需要预览对拍的子合成顶部（可带负 startTime 对齐）。

**用途**：任何嵌套深度打开合成都对同一音频时间轴工作；换音频版本只改一处。注意它不是振幅驱动（整类工程可以完全不用音频振幅表达式），是**时间同步基准**。

**Agent 配方**：新建 50x50 合成 → 放音频层 → 在每个子合成 `layers.add(comp)` 后设 `enabled=false` 并明确 `audioEnabled` 的预览/输出策略。批量引用一个合成对象即可，AE 自动共享。

## 4. 双语歌词条带 `[待验证]`

**结构**：
- 一句歌词 = 一个 TextLayer，**用稳定 lyric_id 定位，层名可包含文本摘要**（检索/批量改时序的关键约定）；
- 原文行 + 翻译行成对，**两条 in/out 完全相同**（原文与译文同时进出），竖向叠放；
- 逐句硬切：上一句 out == 下一句 in，需要对拍的边界落在节拍网格上；**层上不打任何动画器/关键帧**，该候选的"动画"是硬切 + 全条带抽帧（见 §5）；
- 所有句子收进一个超宽条带合成（如 1920x147），作为单层挂进总时间线，可加 `ADBE Drop Shadow`。

**候选样式参数**（示例起点，由当前 brief 调整）：字号例如 64px（1080p），fill 深色、`applyStroke=true` + strokeWidth 5（描边同族深色），`tracking 例如 150`（千分制大字距，松排是这类字幕的观感核心），字体按当前语言、缺字情况和许可选择。日语用 JP 字体、中文用 CJKsc 字体分开配。

**Agent 配方**：按歌词 manifest 逐句建层 → 层 tag=lyric_id → in/out 取自人声时序，仅在语义允许时量化到拍点 → 回读 inPoint/outPoint 链（上一 out == 下一 in，无重叠无空洞，除呼吸段）。

## 5. 抽帧节奏（Posterize Time）`[待验证]`

**机制**：`ADBE Posterize Time`（matchName，显示名"抽帧/Posterize Time"），参数 1 = 帧率（数值型，**可打关键帧**做中途变化）。

**两种挂法**：
1. **调整层挂法**：一个调整层只盖目标拍段（in/out 落拍点），影响其下所有层；总时间线上多个短命「抽帧」调整层与内容层交替；
2. **内容层挂法**：直接挂到背景/字幕条带/单个素材层上，全段生效。

**候选帧率档位表**（30fps 工程内）：

| 值 | 用途 |
|---|---|
| 23.976 / 24 | 电影感段落（尾段、抒情段） |
| 18 | 中度卡顿段落（常见主档） |
| 15 | 强卡顿、节奏重击段 |
| 6-10 | 字幕条带、液体/背景动画（手工感） |
| 5 | 窗帘/大幅背景（极强卡顿） |
| 30 (=comp fps) | 中性值，等于不抽 |

**Agent 配方**：段落节奏 = 建 `create-adjustment-layer` + `addProperty("ADBE Posterize Time")` + set 帧率 + in/out 量化拍点；背景手工感 = 挂内容层 5-10fps。回读参数值与层 in/out。

## 6. 大字/图形入场：硬弹 + 弹性衰减 `[待验证]`

**候选语法**（ShapeLayer 大字，示例数值）：
- Scale：`0% -> 100%`，**2-3 帧内完成**（时长用当前 fps 换算），线性/贝塞尔均可——硬弹出框；
- Rotation：`30° -> 0°` 3-4 帧内完成（带初角度的旋入）；
- 之上叠弹性过冲表达式（惯性弹跳）：

候选阻尼模型：`offset(t) = amplitude * sin(2*pi*frequency*t) * exp(-decay*t)`。先用自建常量做小样，再按目标属性类型和最后一个 key 的速度决定是否引入惯性；表达式未在本次 AE 环境执行。

- 要点：过冲量取自**最后一个关键帧处的速度**（`velocityAtTime`），所以 key 的速度越猛弹得越狠；不用装任何插件。
- 参数 UI：用伪效果（`Pseudo/...` matchName，如 "Elastic: Rotation" 三滑块）当表达式面板；伪效果的保存与重建行为需在目标版本和 preset 上探测，但**表达式本身不依赖伪效果存在**——也可以直接把三个数字写死进表达式。
- 该语法同样用于背景循环：`loopOut('cycle',0)` 挂 Position（分离维度后挂 `_0`/`_1` 子属性）做无缝位移循环。

**总原则**：这类 MV 的文字动画以「2-4 帧硬弹 + 弹性衰减 + 拍点硬切 + 低 fps 抽帧」组合出爆发感；缓入缓出慢动画只用于抒情段。

## 7. 超尺寸画布运镜 `[待验证]`

段落背景合成画幅故意大于交付画幅（例如高于交付画幅的长卷），配合层位移/相机竖向平移长卷。识别法：大画幅只是线索，需要核对内容和引用关系，不要"修复"其画幅。自建时：长卷合成 → 挂进 Main → 对该层 Position 打拍点量化 keys 或挂相机。

## 8. 混合帧率交付（60fps 容器）`[待验证]`

模式：交付合成设 60fps，但**不重做动画**：
- 主体 = 一个命名显眼的占位层（如 `MAIN_VIDEO_PLACEHOLDER`，禁用），等 30fps 工程外部渲染后回填为素材；
- 仅真正需要 60fps 的短段（如片头 0.5s）用外部插值好的 60fps 素材；
- 片头叠层（文字/图形）直接在 60fps 合成里重做；
- 音频以素材层放最底，保证交付合成时长 = 音频时长。

**Agent 边界**：渲染该类合成前必须检查占位层是否已回填，否则输出缺正片。

## 9. 角色绑定：控制参数 + 表达式 rig `[待验证]`

- 控制层用自建 Slider/Checkbox/状态索引，部件层用稳定标识定位；表达式引用明确的控制实例。
- 头发/装饰摆动按部件相位错开；优先小幅测试，再检查 parent、关键帧、expressionError 与运动边界。
- 第三方伪效果需探测保存、重建、依赖与求值行为，不猜内部 API 或固定属性索引。

## 10. 第三方效果依赖与降级 `[待验证]`

第三方效果按当前需求与可用性选择；记录安装版本、effect matchName、许可和缺失时的降级方案，不把特定工程的效果清单当默认。

- 判定法：遍历 Effect Parade，前缀只作线索；按目标 AE 可用效果枚举与依赖清单确认，不能仅凭非 ADBE 前缀判为第三方；本机未装的第三方效果在打开工程后保留占位行，结构可能仍可读取，但参数树与渲染都需检查；缺失依赖时不得报告视觉验证通过。
- 缺插件时的内置替代基线：调色 `ADBE CurvesCustom`+`ADBE HUE SATURATION`、辉光 内置 Glow、半色调 无直接内置（可用形状/网格近似）、镜头光晕 `ADBE Lens Flare`、粒子 `CC Particle Systems II`、抖动 手写 wiggle 表达式、故障 `ADBE Venetian Blinds`+位移/通道分离近似。

## 11. Agent 执行注意（ExtendScript 候选）`[待验证]`

- 保留字陷阱：`final` 等不能用作对象键/变量名，报 `SyntaxError: 非法使用保留字`（带行号，中文 AE 下报错也是中文）。
- 性能：百合成级工程全量扫描（每层每属性）按目标环境测量耗时和 timeout；能分轮查询就不要一次全扫。
- Z 旋转用 `ADBE Rotate Z`（不是 `ADBE Rotation`）；分离维度后 Position 变成 `ADBE Position_0/_1` 子属性。
- 文字样式回读走 `ADBE Text Properties > ADBE Text Document` 的 `value`（TextDocument 对象）；tracking 单位为千分之一 em。

## 12. 复用边界

- 本卡是**结构与做法语法**：架构、量化、表达式、参数档位可自由复用。
- 任何具体素材、镜头设计、歌词文案、字体角色分配属于原作者表达，不得复制；设计仅可"稍稍参考"（如字距/描边档位、抽帧节奏选择这类参数级借鉴）。

## 13. 3D 相机 Rig 运镜 `[待验证]`

**触发**：需要镜头推进/平移/飞过空间，且希望把相机参数与运动手柄分开。

**Rig 结构（候选）**：
```text
Camera_Rig     # 父级 3D Null 承载运动
└─ Camera 1    # 单节点 one-node 相机，parent=Camera_Rig，静态零 keys
3D 内容层       # 文字/视频/形状 threeDLayer=true，铺在隐空间，相机飞过
```

- 相机本体是**单节点**（无目标点 POI keys），在当前场景中设置明确位置。相机距主体的关系需按场景坐标、朝向与 parent chain 判断。
- **所有运动都写在父 null 的 Transform 上**：运镜路径在 null 的 Position。**注意常用「分维度 X/Y 单独打点」**（主 Position numKeys 可能显示 0，但 X 位置 N keys、Y 位置 M keys），另带 Scale/Rotate 分维度 keys。确认时分别回读 null 的 X/Y 位置 keys，相机与 Null 的 key 职责需明确，避免叠加非预期运动。
- null 的 Scale keys 常见但多属**分维度/次要**；2D null parent 3D camera 时 Scale 对子级贡献行为尚未验证，勿当缩放手段写死（推拉靠相机 Z 或内容层）。
- 关键帧以 BEZIER 打点、错开 hold，形成"推进→停→横移→回"的运镜节奏。

**Agent 配方（自建）**：
1. `create-camera`（oneNode=true）放 `[960,540,-2500]` 左右；
2. 建 null（`create-null` 或 solid+nullLayer），**threeDLayer=true（3D Null）**、不透明度 0，命名 `Camera_Rig`，parent 相机到它；
3. 要运镜的层设 `threeDLayer=true` 并分配 Z；
4. 只对 null 的 **X/Y 位置分维度**打拍点量化 keys（见 §2 节拍网格）；
5. 校验：回读 null X/Y 位置 keys + 相机 parent=null + 相机零 keys；抽样帧确认构图。

**超尺寸背景**：先检查引用关系与构图意图；背景本体可保持静态，由相机或父级 Null 扫过。不要仅凭尺寸认定它是长卷。

**节拍震屏辅助**：`!Main` 顶层放多个短命 `Beat Shake` 调整层（盖目标拍段），效果 = `ADBE Geometry2`（Transform）keyed；另有禁用的参考空层做运镜手/抖动标记。宽银幕用 `21:9` 黑条 ShapeLayer（负 startTime 保持位置）。

## 14. 大字/逐字文字动画 `[待验证]`

**触发**：副歌/歌词大字卡、逐字蹦跳、3D 字幕；内置文字动画器和逐字层都是可选实现。

### 14a. 逐字词卡

- 一句一卡，每字符/词组独立层，或用内置 Text Animator；文本粒度由节奏决定。
- 错帧示例为 2–3 帧/字；入画方向独立编排，Position 分为入场、阅读、退场。
- 强调时可用短 HOLD 显隐或 Scale 过冲；不把多次闪烁当所有歌词的默认。
- 空心文字使用 `applyFill=false`、`applyStroke=true` 与有效 strokeColor/strokeWidth；写回 TextDocument 后检查代表帧。

### 14b. 3D 标题与滚动字幕

- 需要深度时启用 3D 并明确相机/parent 关系，文字位置与字号按安全区和阅读需求标定。
- 描边副本可 parent 到主字，但先检查 parent 导致的位移/旋转/Scale 叠加；复制层不是天然正确的轮廓。
- 横扫字幕在阅读区保持足够时间，回读起/止位置、timing 与遮挡；阴影/Glow 只作辅助。

### 14c. 验收

- 核对字符顺序、实际字体、layer/animator 结构、key times/interpolation、in/out 与 expressionError。
- 入场/稳定/退场代表帧与真实输出共同检查；缺少视觉通道时只报告结构结果。
